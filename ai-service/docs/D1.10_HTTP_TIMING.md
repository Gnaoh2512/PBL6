# D1.10 — HTTP transport timing: plan đã bổ sung và kiểm chứng

Baseline khảo sát: `6478073`, Windows, HTTPX 0.28.1 / httpcore 1.0.9 đã cài. Không đọc `.env`
hoặc secrets. D1.9 chỉ chứng minh timeout ở generateContent, chưa tách network/provider waiting.

## Plan bổ sung trước implementation

1. Observer + unit tests trước; sau đó integration test extension forwarding; cuối cùng gắn provider.
2. Dùng `extensions={"trace": callback}` theo request, không sửa global hooks, transport hoặc private pool.
3. Protocol request chỉ từ bytes allowlist trong `response.extensions["http_version"]`; thiếu thì unknown.
   Không dùng `Response.http_version`, vì HTTPX trả HTTP/1.1 mặc định khi extension vắng mặt.
   `trace_family` chỉ là namespace code path đã quan sát, không phải protocol của request/origin.
4. Callback không đọc/giữ `info`, không I/O hoặc await bên trong. Summary dùng queue 128 bản ghi,
   put_nowait, worker daemon thực hiện I/O. Queue đầy/sink lỗi mất record có đánh dấu loss ở record sau;
   không chờ flush/join trên request/cancellation/client-shutdown. Đây là delivery best effort.
5. Clock/observer/emitter lỗi thông thường không thay exception gốc. Không shield/uncancel/retry;
   test chặn sink và kiểm tra cancellation trả về trước khi thả sink, đúng exception object/cancel count.
6. Không chạy live, đổi model/prompt/deadline 20 giây/token-call budget/no-retry/readiness/dependency.
   Không đổi FE/BE, corpus, dataset hoặc artifact/báo cáo D1.9. Chỉ commit đúng phạm vi trên nhánh riêng.

## Ý nghĩa và giới hạn phép đo

| Phase | Khoảng đo ở client | Không được suy ra |
| --- | --- | --- |
| connect_tcp | Backend connect bắt đầu → kết thúc/lỗi | DNS và TCP riêng; có thể gồm nhiều địa chỉ/scheduling |
| tls/proxy_tls | start_tls bắt đầu → kết thúc/lỗi | RTT/compute thuần hoặc host đích; proxy có thể là endpoint |
| write_headers/write_body | Thư viện gửi headers/body | Server đã nhận/ACK; duration có buffering/flow control |
| wait_headers | Đợi/parse response headers | Gemini compute, queue hoặc TTFB thuần |
| read_body | Consumer đọc stream | Thời gian truyền toàn body; bytes có thể đã buffered khi đọc headers |
| close | Cleanup response được trace | Toàn bộ client/pool shutdown |
| pre_trace_ms | Bắt đầu request → trace đầu | Pool wait riêng; gồm chuẩn bị/lock/scheduling |

Không quan sát phase: unavailable (không tạo sample, không ghi 0). Event thiếu kết thúc: elapsed
đến abort, không phải latency hoàn tất. Không có connect/TLS không chứng minh reuse. Không cộng
parent/child spans. Không lấy pool/DNS/provider timing bằng phép trừ hoặc suy từ exception message.

## Schema và giới hạn an toàn

Logger riêng `ai_service.http_timing`, JSON, schema_version=1/event_type=http_timing. Giữ nguyên
schema/logger D1.8. Summary gồm diagnostic_id/http_attempt_id UUID nội bộ, operation/method enums,
protocol/protocol_source, outcome/category, HTTP status khi có, duration/remaining budget,
trace_state (observed/partial/unavailable), pre_trace_ms, truncated, delivery_loss_observed và samples.
Mỗi sample: phase/trace_family/sequence/outcome/duration_ms/duration_kind. Tối đa 32 samples.

Protocol: HTTP/1.0 hoặc HTTP/1.1 bytes → http1, HTTP/2 bytes → http2; nguồn response_extension.
Không có explicit extension hợp lệ → unknown/unavailable, kể cả khi thấy http11/http2 trace event.
Không serialize URL/host/IP, headers/body, prompt/response, key/JWT/PII, request/account ID của khách,
path, stream ID, raw exception hoặc traceback. Callback không đọc info kể cả để lấy status/protocol.

## Kiểm chứng bắt buộc

- Unit clock deterministic: đủ phase, missing/unknown/repeated/overflow, schema/redaction/context isolation.
- Integration: HTTPX client riêng → adapter test dùng API public → httpcore pool thật với backend/stream
  giả; chứng minh callback nhận event thật, request sau không trace không bị ảnh hưởng. Không private pool.
  Test này không mở network/TLS thật; forwarding trong default HTTPX được xác minh thêm bằng source.
- Chậm/lỗi/cancellation connect/TLS/write/headers/body; pooled reuse, thiếu trace, proxy/HTTP2 synthetic.
- Observer/emitter/sink lỗi: exception identity/mapping không đổi, cancellation không await I/O hoặc drain;
  stream/client cleanup và request tiếp theo đúng. Budget tích lũy không được reset.
- Full offline tests với outbound guard; Ruff, pip check, link/diff/preservation checks.

Overhead không bằng 0: clock reads/cấp phát/queue; worker I/O có thể tranh CPU và record cuối có thể mất
khi process thoát. Không thêm await để bù/flush và không đổi deadline. Dừng nếu cần private pool/monkeypatch
runtime hoặc có regression cancellation/budget/error mapping/cleanup chưa xử lý được. Chưa chứng minh
root cause D1.9 hoặc độ ổn định live; D1 vẫn mở.
